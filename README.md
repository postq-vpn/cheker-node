# Решала 🚀

**Решала** — консольный (TUI) фреймворк для управления VPN/Reality-серверами на Linux (Debian/Ubuntu). Один скрипт, одно меню: безопасность, диагностика, трафик, обслуживание сервера и управление целым флотом серверов через Skynet — без десятка разных бэш-скриптов, разбросанных по истории терминала.

Автономно определяет, что установлено на сервере (панель/нода Remnawave, бот Bedolaga, веб-сервер), и подстраивает под это дашборд и меню.

## Установка

```bash
wget -O install.sh https://raw.githubusercontent.com/postq-vpn/cheker-node/main/install.sh \
  && bash install.sh \
  && reshala
```

Требуется root (или sudo) на Debian/Ubuntu. Установщик — просто загрузчик: скачивает актуальный код из ветки `main` и запускает установку.

## Дашборд

Главный экран показывает: ОС, ядро, аптайм, CPU/RAM/диск, публичный IP и локацию, статус Remnawave (панель/нода/подписка), вместимость (свою и по всему флоту), статус шейпера трафика — и блок **виджетов**, которые можно включать и выключать поштучно (`[w]` в главном меню).

Виджеты из коробки: курс BTC, короткая нагрузка системы, число активных пользователей, «Флот онлайн» (сколько серверов Skynet отвечает прямо сейчас) и статус серверов категории «Инфра» по последней проверке ТСПУ. Свой виджет пишется по шаблону из `docs/GUIDE_SKYNET_WIDGETS.md` — один файл в `plugins/dashboard_widgets/`, без правок остального кода.

## Возможности

### 🌐 Skynet — управление флотом
Одна база серверов (`~/.reshala_fleet`), доступ по SSH-ключам, которые Решала сама генерирует и раскладывает.

- Добавление/удаление серверов, категории **Флот** (VPN-ноды) и **Инфра** (панели, control-plane — считаются отдельно от VPN-вместимости);
- выполнение произвольных плагинов на всём флоте или выбранных серверах (`plugins/skynet_commands/`);
- ручной редактор базы, авто-скан доступности, управление SSH-ключами;
- замер вместимости по всему флоту одним запуском (Ookla + расчёт числа пользователей);
- **проверка блокировки ТСПУ** — доступность IP каждого сервера из сетей российских операторов через реальные зонды RIPE Atlas (без захода на сервер по SSH), с разбивкой по городам и операторам и отчётом в Telegram по расписанию несколько раз в день.

### 🛡️ Безопасность
- Firewall (UFW), Fail2Ban, усиление ядра (Kernel Hardening), сканер руткитов (rkhunter);
- управление портами SSH с авто-синком Firewall/Fail2Ban;
- единый **Глобальный Белый Список** для всех модулей защиты;
- бэкап и восстановление конфигураций безопасности;
- сводный отчёт по всем компонентам защиты одним экраном.

То же самое (harden SSH, порт, UFW, Fail2Ban, kernel, rollback) можно прогнать удалённо на любом сервере флота через Skynet.

### 🚦 Трафик и сеть
- Шейпер трафика на базе eBPF + EDT — точное ограничение скорости по IP;
- BBR + CAKE одной командой, включение/отключение IPv6;
- TLS Reality Scanner (PRO) — поиск подходящих SNI для обхода блокировок.

### 🔧 Обслуживание сервера
- Обновление системы (`apt update && upgrade`) с лечением типичных EOL-ошибок;
- speedtest (Ookla), профиль нагрузки дашборда (частота опроса метрик);
- умное управление памятью — ОЗУ, ZRAM, диск-swap;
- коллекция сторонних диагностических скриптов с собственной сортировкой;
- диагностика и логи Решалы, панели, ноды и бота в одном месте.

### 🧹 Автообновление и очистка
- Централизованный **Автообновлятор** — сканирует и обновляет настроенные сервисы по выбранной стратегии;
- глубокая очистка Docker, APT и логов с анализатором диска;
- самообновление самой Решалы + движок миграций для критических изменений между версиями.

## Как это устроено

Меню строится автоматически: каждый модуль объявляет свои пункты через `@menu.manifest` / `@item(...)`, а `modules/core/menu_generator.sh` сканирует все файлы и собирает из них дерево меню — новый модуль не требует правок роутинга.

Подробная структура — в [`docs/Структура.md`](docs/Структура.md) и [`docs/GUIDE_MODULES.md`](docs/GUIDE_MODULES.md). Как писать свои плагины для Skynet и виджеты дашборда — в [`docs/GUIDE_SKYNET_WIDGETS.md`](docs/GUIDE_SKYNET_WIDGETS.md), стандарты кода и UI — в [`docs/STYLE_GUIDE.md`](docs/STYLE_GUIDE.md).
